# Daily Climb — beta

The test copy of Daily Climb at **beta.thedailyclimb.com**. Same game code as
the live site (thedailyclimb.com), but on this address it runs in beta mode:
no online database (a pretend one kept on your device), a BETA badge, and
test tools (play any date, replay a day, reset to a new player).

Changes land here first; the live game only changes once they're approved.
